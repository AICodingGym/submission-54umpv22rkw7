# 同一模型三个 seed 推理取平均

模型为 λ=0.1 的第 4 轮检查点，seed 为 42、17、2026。开启现有 p=0.1 dropout，模型权重不变；对连续回归分数取算术平均后再分档。

普通 eval 模式的 32 篇检查显示三个 seed 输出相同；随机推理同 seed 复现通过，不同 seed 输出不同。

| 选择集方案 | QWK |
| --- | ---: |
| 普通推理 B0 | 0.815469 |
| 普通推理 B1 | 0.830019 |
| 三次平均 B0 | 0.809063 |
| 三次平均＋原 B1 阈值 | 0.821330 |
| 三次平均＋重新校准 B1 | 0.823802 |

B1 重校准仅使用 calibration；未评估 final_validation，未提交平台。三份逐次预测、均值和标准差保存在各 split 的 CSV 中。
此实验是一个检查点的 MC dropout，不是三个独立训练模型的 seed ensemble。推理顺序与 batch size 固定为原始数据行顺序经 token 长度排序、batch 4；不同 batch 划分可能改变随机 mask。
CSV 核验时先还原各次预测的 float32 类型，再以 float64 重建平均值，以避免小数文本解析引入的精度差异。
